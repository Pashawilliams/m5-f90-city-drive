# BMW M5 F90 — City Drive 3.0

Браузерная аркадная гонка на **Babylon.js 9.29** с физикой **Havok (WASM)**.
Работает без установки, прямо в браузере.

### ▶ Играть: https://pashawilliams.github.io/m5-f90-city-drive/

## Управление
| клавиша | действие |
|---|---|
| `W` / `S` | газ / тормоз (на месте — задний ход) |
| `A` / `D` | руль |
| `Space` | ручник (дрифт) |
| `C` | камера: погоня / капот / бампер / кино |
| `Tab` | карта |
| `Esc` | пауза и меню |
| `F` | полноэкранный режим |

## Физика
Собственная raycast-подвеска поверх твёрдых тел Havok, шаг 120 Гц:

* пружина и демпфер с раздельными ходами сжатия и отбоя, стабилизаторы поперечной устойчивости;
* модель шины Пацейки — продольное и поперечное скольжение, круг сцепления, зависимость сцепления от нагрузки;
* перенос массы при разгоне, торможении и в поворотах, крены кузова;
* аэродинамическое сопротивление и прижимная сила;
* гидротрансформатор на старте, 8-ступенчатый автомат, переключения по оборотам колёс.

Замеры прямо в игре: **M5 F90 — 0–100 км/ч за 3.2 с** (у реальной 3.2–3.4 с),
**Hypercar GT — 0–100 за 2.6 с, 0–200 за 6.5 с, максималка 335 км/ч**.

## Графика
PBR-материалы, HDR-окружение, каскадные тени, SSAO, экранные отражения, bloom,
время суток, процедурный город с инстансингом.

## Автомобили
`BMW M5 F90` (процедурная модель) · `Ferrari 458` · `Hypercar GT` · `Endurance LMP` ·
`Wedge 80s` · `Rally Raid` · `Streamliner`

## Локальный запуск
```bash
git clone https://github.com/Pashawilliams/m5-f90-city-drive.git
cd m5-f90-city-drive
python -m http.server 8080
```
Открыть http://localhost:8080/ — просто двойным кликом по `index.html` не заработает:
браузер запрещает загрузку ассетов по `file://`.
